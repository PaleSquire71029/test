# ETHERIA — 回声大陆

一款以探索为核心、具有原神式空间层级和移动端操作逻辑的 2D 开放世界 RPG。

**目标**：让玩家打开之后，忘记自己是在浏览器里玩。

## 在线游玩

项目为纯静态 HTML / CSS / JavaScript，不依赖后端。通过 GitHub Actions 自动部署：

`https://palesquire71029.github.io/test/`

> 首次部署或更新后可能需要等待一段时间生效。请在 **Settings → Pages** 中确认发布方式为 GitHub Actions。

## 核心体验

- **世界是绝对主角**：屏幕 90% 以上是地图、角色和环境，HUD 极度克制
- **探索驱动**：看到 → 好奇 → 靠近 → 发现 → 互动 → 得到结果
- **环境叙事**：回声碎片、奇怪的石碑、被破坏的营地——玩家自己把故事串起来
- **区域式开放世界**：晨雾谷 → 静谧森林 → 风痕高地 → 暮潮湖畔，自然形成探索路线

## 游戏系统

### 世界探索
- **回声碎片**：共 9 枚，玩家不知道总数，每块讲一点故事，逐渐拼出大陆的秘密
- **营火**：恢复生命，也是传送点
- **隐藏宝箱**：需要击败敌人、解谜或探索隐藏区域；有些完全不显示，需要绕到瀑布后面才能发现
- **环境资源**：木材、铁矿、晨雾草、野果、晶矿、水草、贝壳——直接长在世界中，不是漂浮的网页图标

### 战斗
- **普攻**：连续攻击，有 combo 系统
- **冲刺**：带无敌帧与位移
- **元素技**：有明显视觉反馈，消耗体力
- **敌人攻击**：提前出现红色范围、动作前摇、音效提示，玩家可以躲避
- **敌人种类**：荒原狼（普通）、岩甲兽（强敌）、岩甲兽·精英（精英）
- **Boss 战：暮岩古龙**：
  - 第一阶段：近距离攻击
  - 第二阶段：范围冲击波
  - 第三阶段：场地变化（落石、危险区域）

### 成长
- 等级、经验、生命值、体力、攻击力
- 武器装备系统
- 背包分类：全部 / 装备 / 消耗品 / 材料 / 任务

### 独立界面层级
- **第一层：世界** —— 最高优先级
- **第二层：HUD** —— 只显示必要信息（雷达小地图、任务追踪、角色状态、战斗条）
- **第三层：游戏界面** —— 角色 / 背包 / 任务 / 地图，各自独立
- **第四层：系统** —— 继续游戏 / 设置 / 保存 / 帮助 / 返回标题

### 移动端
- 强制横屏 + 全屏
- 左下虚拟摇杆
- 右下主次分明的战斗按钮：普攻（最大）> 元素技 > 冲刺 > 互动（条件出现）
- 安全区与短屏布局适配

### 音频
- 环境底噪 + 低频 drone，随位置变化
- 靠近湖水：高频通透感增强
- 靠近遗迹：音调降低，氛围更沉
- 动作音效：攻击、拾取、受伤、升级、回声碎片

### 存档
- 自动保存（每 20 秒）
- 本地存储：玩家状态、世界探索进度、已开启宝箱、已收集碎片、敌人击杀状态、Boss 血量、迷雾地图

## 操作

**桌面端**
- WASD：移动
- Shift：疾跑
- 空格 / 左键：攻击
- Q：元素技
- E：互动
- M：地图
- Esc：菜单

**移动端**
- 左侧摇杆：移动
- 右下按钮：战斗与互动

## 技术栈

- HTML5 Canvas 2D 渲染
- 原生 JavaScript（无框架依赖）
- Web Audio API（环境音与音效）
- localStorage（本地存档）
- GitHub Actions（自动部署）

## 部署

仓库 `main` 分支推送会触发 `.github/workflows/pages.yml`。

所有运行数据保存在玩家浏览器本地，无需服务端。
